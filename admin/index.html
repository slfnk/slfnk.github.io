Sign in with a GitHub token

The editor saves straight to your site's GitHub repo. It needs a token that can only touch that one repo.

  1. Open GitHub → new fine-grained token.
  2. Name it "GUIIDES editor" and pick an expiration (90 days is sensible).
  3. Under Repository access, choose Only select repositories → .
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Generate, copy it, and paste it below. Don't paste it anywhere else.
